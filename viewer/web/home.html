Biodiversity FAIR Data Point

Static FDP profiles for biodiversity infrastructures, kept as Turtle in GitHub. Each catalog lists every way to get a resource: native portals and APIs, bulk files, cloud buckets and copies in aggregators. Browsing needs no account; editing commits to the repository and needs a GitHub sign-in.

FDP browser
Index → catalog → dataset → distribution, with how-to-access notes and endpoints.
